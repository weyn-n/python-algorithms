# Python Algorithms

A collection of algorithmic problems and solutions written in Python.

The repository is used to practice:

* Python fundamentals
* Data structures
* Algorithms
* Problem solving
* Code optimization

## Topics

* Dictionaries
* Lists
* Strings
* Loops
* Searching
* Sorting

## Structure

Each algorithm is stored in a folder based on the main concept used in the solution.

```text
python-algorithms/

├── strings/

├── searching/
└── sorting/
```
